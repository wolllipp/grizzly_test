# Enemer Frontend

SvelteKit frontend application for Enemer logistics company.

## Prerequisites

- Node.js 18+
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

App runs at [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
